# Milestone 4 package: diabetes and heart-disease modules

This zip contains the complete `ml/` and `backend/` folders as they stand with M4 (the folders also contain the image-module
code from M5, which stays inactive unless you install an image model). The React frontend (M3) needs no change:
it builds its forms from the API.

1. `pip install -r backend/requirements.txt` in a virtual environment
2. Follow `docs/M4_MULTI_DISEASE.md` (train the three models, run the tests)
3. Results with every number: `docs/RESULTS.md`; trained figures: `ml/evaluation/figures/`
