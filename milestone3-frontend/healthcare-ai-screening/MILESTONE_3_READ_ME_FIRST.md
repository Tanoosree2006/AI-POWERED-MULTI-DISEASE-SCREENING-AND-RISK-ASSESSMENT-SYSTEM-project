# Milestone 3 package: React frontend

This zip holds the **frontend only** (`frontend/`), the API contract it was built against (`openapi.json`) and `.env.example`.
To run it you also need the backend from the full project zip (`healthcare-ai-screening-FULL.zip`): the frontend talks to
the FastAPI server (M2) and the trained models (M1, M4). Follow `frontend/README.md`.

Order of work: (1) full project zip: train models, start the backend; (2) this frontend: `npm install`, `npm run dev`.
